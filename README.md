# Air India Homepage Demo

A responsive, front-end-only airline homepage inspired by Air India's red, white, and dark visual identity. This is an independent demo, not the official Air India website; flight searches and offers are illustrative and do not make bookings.

## Features

- Responsive navigation with a mobile menu
- Hero banner and flight-search form
- One-way and round-trip options, date validation, passenger and cabin selectors, and route swapping
- Sample offers and popular destination cards
- Responsive footer and travel-information callout

## Run locally

1. Download or clone this project.
2. Open `index.html` in a modern browser.

No build step, framework, or package installation is required. The photography is loaded from Unsplash, so an internet connection is needed to display the images.

## Project files

- `index.html` — page content and accessible form controls
- `style.css` — layout, responsive breakpoints, and visual styles
- `script.js` — mobile navigation and demo flight-form interactions
